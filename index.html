How to install:

you need iris

you need bsl shaders

you have to turn on pbr settings in bsl

click the resource packs button

now drag the resource pack (not src folder) into the resource packs

enable the pack

How to make from source:

create a .zip file with your favorite zipping program

open it and drag all the src files in

how to mod:

to mod the resourcepack you open the src folder go into assets/minecraft/textures/block/ and then you can edit the blocks

once done modding follow steps from the making guide

Bug reports And requests

any bug reports or requests? post in issues of PixelPbr-SOURCE/pv(pack version)mcv(mc version)

some bugs are unfixable though.
